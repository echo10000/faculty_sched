Configure verified room specializations

Use the existing room-type categories to describe verified facilities. For example, a high-spec computer laboratory and a networking / multimedia laboratory can be separate categories when their equipment has been verified. General classrooms can use a lecture category. These examples do not assign subjects or assume any campus room has equipment.

Each room has one specialization. Mandatory class requirements match that category exactly; a broad Laboratory category does not automatically match a specialized laboratory category. Room names and building names are not equipment checks.

Room ownership controls access through the existing organizational scope. Active status, category, building and class capacity affect suitability. A suitable room may still be occupied or blocked at a particular time.
